A continuacion se muestran los pasos para clonar, desplegar y usar correctamente el proyecto

1- Clonar el proyecto
2- Ejecutar el dump de base de datos (Esta en el correo. Tambien en el repositorio)
3- Crear Archivo .env basado en example
4- Instalar las dependencias (npm install)
5- Ejecutar "prisma generate" la consola dentro del proyecto. (Permite a prisma entablar conexion con db)
6- probar con npm run dev
7- Crear dist con npm run build y probar con npm start
